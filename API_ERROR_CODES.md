# Platform API Error Codes & Contract Specification

This document formalizes the error codes, HTTP status mapping, retry semantics, and frontend handling contracts across the Production ERP & Storefront platform API.

---

## 📋 Standard Error Envelope

Every failed API response conforms to the standard error envelope generated by `App\Core\Http\Responses\ErrorResponse`:

```json
{
  "error": {
    "code": "ERROR_CODE_STRING",
    "message": "Human-readable description of what failed.",
    "retryable": false,
    "correlation_id": "req-uuid-or-id",
    "details": {}
  }
}
```

---

## 🚨 Canonical Error Code Catalog

### 1. `TENANT_INACTIVE` (GAP-003)
- **HTTP Status:** `402 Payment Required`
- **Exception Class:** `App\Core\Tenancy\Exceptions\TenantSuspended`
- **Trigger Condition:** The tenant's subscription status is `suspended`, `cancelled`, or `expired`, or the tenant workspace has been manually deactivated by a platform super-admin.
- **Retryable:** `false`
- **Backend Middleware:** `EnsureTenantActive.php`
- **Frontend Action Required:** 
  - Immediately log the user out or redirect to `/subscription/past-due` or `/tenant-inactive`.
  - Display billing settlement dialog or prompt user to contact the account administrator.
  - Do NOT automatically retry requests when receiving `TENANT_INACTIVE`.

```json
{
  "error": {
    "code": "TENANT_INACTIVE",
    "message": "Your account is currently inactive. Please contact support or settle any outstanding balance.",
    "retryable": false
  }
}
```

---

### 2. `UNAUTHENTICATED`
- **HTTP Status:** `401 Unauthorized`
- **Exception Class:** `Illuminate\Auth\AuthenticationException`
- **Trigger Condition:** Missing, invalid, expired, or revoked JWT Bearer token, or tenant ID claim missing from token.
- **Retryable:** `false`
- **Frontend Action Required:** Clear local auth session state (`auth_user`, `auth_tenant`, `auth_permissions`, `auth_branches`, `auth_active_branch`) and redirect to `/login`.

---

### 3. `OUT_OF_SCOPE`
- **HTTP Status:** `403 Forbidden`
- **Exception Class:** `App\Core\Tenancy\Exceptions\OutOfScope`
- **Trigger Condition:** The user holds the required permission dot-string, but the target resource belongs to a branch, department, or warehouse outside the user's explicit `user_scopes`.
- **Retryable:** `false`
- **Frontend Action Required:** Display `<NoPermissionState />` or toast alerting that the record belongs to another branch/warehouse.

---

### 4. `PERMISSION_DENIED`
- **HTTP Status:** `403 Forbidden`
- **Exception Class:** `Illuminate\Auth\Access\AuthorizationException`
- **Trigger Condition:** The user's role lacks the specific `{module}.{entity}.{action}` permission required for the endpoint.
- **Retryable:** `false`
- **Frontend Action Required:** Display `<NoPermissionState />` or disable the trigger button beforehand using `authStore.hasPermission()`.

---

### 5. `TENANT_MISMATCH`
- **HTTP Status:** `400 Bad Request` / `403 Forbidden`
- **Exception Class:** `App\Core\Tenancy\Exceptions\TenantMismatch`
- **Trigger Condition:** The request body supplied a `tenant_id` that directly conflicts with the authenticated JWT tenant claim (security isolation event).
- **Retryable:** `false`

---

### 6. `VALIDATION_FAILED`
- **HTTP Status:** `422 Unprocessable Content`
- **Exception Class:** `Illuminate\Validation\ValidationException`
- **Trigger Condition:** Input payload failed FormRequest schema validation.
- **Retryable:** `false`
- **Payload Details:** `details` map keyed by field name containing error strings.
- **Frontend Action Required:** Populate `react-hook-form` field errors or toast validation message.

---

### 7. `IDEMPOTENCY_CONFLICT`
- **HTTP Status:** `409 Conflict`
- **Exception Class:** `App\Core\Http\Exceptions\IdempotencyConflictException`
- **Trigger Condition:** An existing in-flight or completed transaction matches the supplied `X-Idempotency-Key` header with different payload parameters.
- **Retryable:** `false`

---

### 8. `NOT_FOUND`
- **HTTP Status:** `404 Not Found`
- **Exception Class:** `Illuminate\Database\Eloquent\ModelNotFoundException`, `Symfony\Component\HttpKernel\Exception\NotFoundHttpException`
- **Trigger Condition:** Requested UUID does not exist within the active tenant's schema partition.
- **Retryable:** `false`
